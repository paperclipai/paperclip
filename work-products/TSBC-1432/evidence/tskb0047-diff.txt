+### TSBC-1432 harness gates - 2026-07-28
+
+The benchmark harness must fail closed on three common false-verdict paths:
+
+- Success-rate floor: if a cell's `successRate` is below `0.8`, publish
+  `quality = null` / `qPer1kOut = null`, carry a `suppressed_reason`, and treat
+  the cell as failed rather than absent or high-scoring.
+- Repetition accounting: `reps` is its own field and is not `n_tasks`. A cell
+  with `reps < 3` may be shown as internal evidence only and must be capped at
+  `candidate`; it cannot produce a decision-grade pick.
+- Pass-level ledger evidence: aggregate `model_eval` rows must be backed by
+  durable `model_eval_pass` rows that record the task id, rep, requested model,
+  served model, served-model verification flag, pass/fail, failure reason,
+  token counts, duration, and start/finish timestamps. If historical artifacts
+  do not prove a field, the row says `unknown`; do not infer or guess.
+- Antigravity truth: until AGY exposes a structured served-model field, every
+  AGY benchmark run must capture the same-run model self-report beside the
+  requested pin. A pin/self-report mismatch is recorded as
+  `failure_reason: served_model_mismatch` and is never scored.
+- Deployed incumbent baseline: any evaluation that could replace or supplement a
+  deployed lane must include the deployed agent, adapter, and true served model
+  as a same-run baseline. A model-name-only substitute is not sufficient; if the
+  deployed baseline is missing, the verdict is `void`.
