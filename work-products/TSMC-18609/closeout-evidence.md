## Decision

Decision recorded before build on Friday, July 31, 2026:

- `tts_gen` is the right routing shape.
- It should be a Paperclip capability-routing toolset, not a Hermes native CLI toolset.
- Reason: the real synthesis path on this machine is an OAuth-backed Grok `/v1/tts` call run from the host, while Hermes currently warns on unknown toolsets such as `tts_gen`.
- Implementation consequence: Paperclip should route on `tts_gen`, agents should advertise it through routing metadata, and the creative lane should execute it through a synced skill plus a local runner script.
