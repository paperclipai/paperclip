---
title: "Interface language"
description: "Choose and persist the language used by the Paperclip board UI."
---

Paperclip selects the board interface language in this order:

1. Your last explicit language choice in the current browser.
2. The first bundled locale matching the browser's preferred languages.
3. English when no preference matches.

To change the language before signing in, use the globe button beside the theme control. After signing in, open the account menu at the bottom of the sidebar and select the row showing the current language.

The choice is stored in the browser, applies immediately, and is not shared between browsers or devices. Screens without translated copy continue to use the English fallback until their locale catalog is complete.
