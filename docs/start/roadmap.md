# Roadmap

Paperclip is still moving quickly. The list below is directional, not promised, and priorities may shift as we learn from users and from operating real AI companies with the product.

We value community involvement. Bugs, docs, polish, and tightly scoped improvements are the easiest contributions to merge. For roadmap-level features, coordinate on [Discord](https://discord.gg/m4HZY7xNG3) first.

## Next Up

### 🔵 Cloud / Sandbox Agents

We want agents to run in more remote and sandboxed environments — Cursor, e2b, Novita, and others — while preserving the same Paperclip control-plane model. This makes the system safer, more flexible, and more useful outside a single trusted local machine.

**Status**: Active exploration

### 🔵 Artifacts & Work Products

Paperclip should make outputs first-class. Generated artifacts, previews, deployable outputs, and the handoff from "agent did work" to "here is the result" should become more visible and easier to operate.

**Status**: Next up after v0.5.0

## Farther Horizon

| Area | Description |
|------|-------------|
| **Enforced Outcomes** | Stricter definition of done — tasks resolve to merged code, published artifacts, shipped docs, or explicit decisions |
| **MAXIMIZER MODE** | Higher-autonomy execution with aggressive delegation, deeper follow-through, and strong governance |
| **Work Queues** | Queue-style work streams for support, triage, review, and backlog intake |
| **Self-Organization** | Agents propose structural changes — role adjustments, delegation, recurring routines — within governance boundaries |
| **Automatic Organizational Learning** | Turn completed work into reusable playbooks, fixes, and decision patterns |
| **Cloud Deployments** | Cleaner shared deployment story for hosted and semi-hosted environments |
| **Desktop App** | A desktop app for easier access, better local ergonomics, and a smoother default experience |
