# Release: v0.5.0 — Market Readiness

**Date**: 2026-08-20
**Type**: Feature release
**Release**: v0.5.0
**Related**: VOY-1336, VOY-1337, VOY-1338, VOY-1339, VOY-1340, VOY-1341, VOY-1342, VOY-1343, VOY-1367, VOY-1474, VOY-1493

## Overview

v0.5.0 is the market-readiness release. It converts Paperclip from a developer-focused control plane into a self-serve product: new users can sign up, onboard a company in minutes, deploy pre-built templates, hire marketplace agents, and run a fully functional AI company — with billing, notifications, and documentation to match.

## What's New

### Self-Service Onboarding (VOY-1337)

- **Email/password signup** — new users can create an account and claim their own company (controlled by the `authDisableSignUp` flag)
- **Onboarding wizard** — `POST /api/start` creates a company, CEO agent, company goal, onboarding project, and a starter task in one request
- **Role packs** — onboarding asset bundles for twelve organizational roles (CEO, CTO, PM, and more), each with tailored skills, knowledge packs, and a starter issue

### Stripe Billing (VOY-1338)

- **Subscription tiers** — tier plans with monthly/yearly billing periods
- **Subscription lifecycle** — create, update, cancel (at period end), reactivate via API
- **Usage reporting** — report and track usage metrics: seats, agent runs, storage GB
- **Invoice sync** — pull invoice history from Stripe, view consolidated billing overview
- **Stripe webhooks** — `invoice.paid`, `invoice.payment_failed`, `customer.subscription.updated`, `customer.subscription.deleted` with signature verification
- **Security** — billing mutations require a board-user context; agents are blocked with 403

### Feature Gating / Paywall (VOY-1609)

- **Subscription feature gating** — `requireFeature` Express middleware gates operations behind tier features; denied requests return `403 PAYWALL`
- **Four gated operations** — API key creation (`api_access`), advanced agent creation (`advanced_agents`), member invites past seat limit (`unlimited_seats`), and marketplace plugin installation (`custom_plugins`)
- **Ten feature keys** — `custom_plugins`, `advanced_agents`, `audit_logs`, `api_access`, `priority_support`, `extended_storage`, `sso`, `custom_roles`, `advanced_reporting`, `unlimited_seats`
- **Degradation handling** — canceled subscriptions lose paid feature access once the paid period elapses
- **Free feature passthrough** — core features in `FREE_FEATURES` bypass all gating checks

### Multi-Channel Notifications (VOY-1342)

- **Five notification types** — `review_requested`, `approval_needed`, `work_completed`, `budget_threshold`, `execution_error`
- **Three channels** — in-app panel, branded HTML email (SMTP), browser web push (VAPID)
- **Per-type preferences** — configure channels and digest frequency (instant/daily/weekly/never) per notification type
- **Digest emails** — daily and weekly summary digests
- **Delivery telemetry** — per-channel delivery status (pending/sent/failed) with error messages and a notification history view
- **Reliability** — fire-and-forget dispatch (failures never break the triggering operation) and runId-based deduplication for execution errors

### Agent Marketplace (VOY-1343)

- **Browse** — list marketplace agents with filters (category, role, free-text search)
- **Hire** — one-click hire with automatic skill installation, default adapter config, and default budget
- **Catalog** — agents sourced from the `@paperclipai/agents-catalog` package
- **Governance** — hire gated behind the `agents:create` permission and company board-approval policy

### Company Templates (VOY-1340)

- **Four production templates** — Travel Concierge, Support Ops, Engineering Team, CPA Firm
- **Atomic deployment** — all-or-nothing; if any critical step fails, the entire operation rolls back
- **Full scaffolding** — each template ships agents, skills, a knowledge starter pack, a company goal, a project, and a starter issue

### Knowledge Starter Packs (VOY-1341)

- **Pre-curated packs** — Engineering and Travel Industry packs, loaded from JSON data files
- **One-call install** — `POST /api/companies/:companyId/knowledge/starter-packs/:packKey/install`
- **Published directly** — pre-curated content skips the draft → review → publish workflow
- **Title-based deduplication** — documents with existing titles are skipped
- **Operator-extensible** — add custom packs by dropping JSON files into `server/src/knowledge-starter-packs-data/`

### Multi-User Team Invites (VOY-1339)

- **Company invites** — invite users with viewer/operator/admin roles
- **Join requests** — structured join-request flow
- **Invite landing page** — accept invites from a dedicated landing page

### Async UX (VOY-1474, VOY-1493)

- **Background jobs framework** — long-running operations run as background jobs with job IDs, progress tracking, and SSE/polling status
- **Process visibility** — BackgroundProcessTray in the sidebar, freshness cues on research items, skeleton loading on trip pages
- **Keyword-first search** — `/research/search` returns instantly with async semantic upgrade via SSE
- **PDF/ICS exports** — background job-based document generation

### Documentation (VOY-1551)

- **New setup guides** — Billing Setup, Notification Configuration, Marketplace Usage, Template Companies, Knowledge Starter Packs
- **FAQ** — common setup and troubleshooting questions
- **Updated quickstart** — "run your first AI company in 5 minutes" covers the full v0.5.0 feature surface
- **Full API reference** — onboarding, billing, notifications, marketplace, company templates, knowledge starter packs

## Breaking Changes

- **Research endpoints return job IDs** — `POST /api/companies/:companyId/research/auto-assess` and activity search now return `202` with a `jobId` instead of executing inline. Clients must poll or subscribe to SSE for results.
- **Billing mutations require board-user context** — agents attempting billing mutations receive `403 Forbidden`.
