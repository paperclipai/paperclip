# Context

Phase 0 must make native-runner development independently runnable without
importing or starting Paperclip core. The accepted implementation plan defines a
mock control-plane tracer, contract sketches, static dependency enforcement,
package-local tutorials, and an OKF v0.2 engineering journal.

> **Supersession note:** Decision 1's TypeScript-only package boundary was
> corrected after the human checkpoint. See the
> [Rust boundary correction](2026-08-07-phase-00-rust-boundary-correction.md).

# Decisions

1. Keep Phase 0 runtime dependency-free; use only Node.js and TypeScript tooling.
2. Model Paperclip as `ControlPlanePort`, local harnesses as `HarnessDriver`, and
   local or hosted normalized execution as `NativeSessionBackend`.
3. Make the mock control plane an in-memory adapter with explicit start/stop,
   ordered event ingestion, and exactly one terminal result.
4. Use one checked JSON fixture and exact serialized output so regressions are
   deterministic.
5. Reject every Paperclip workspace dependency and every relative import that
   escapes this package. Future public-schema exceptions require a reviewed
   allowlist change.
6. Use OKF v0.2's `generated` actor/time family rather than the superseded v0.1
   `timestamp` convention.

# Failures

- The first filtered install encountered pnpm's existing-modules reinstall
  confirmation and left a local `pnpm-lock.yaml` importer even though the
  command requested no lockfile. The lockfile change was removed because GitHub
  Actions owns it in this repository.
- The first full `verify` rerun failed immediately with `tsc: not found` because
  the execution shell sets `NODE_ENV=production`, so the preceding filtered
  install had omitted package development tools. The install and tutorial now
  pass `--dev` explicitly. A non-interactive repeat with `--dev`, `--force`,
  `--lockfile=false`, and `--offline` restored the package tools without a
  download; the following `verify` completed successfully.
- No build, test, boundary, documentation, OKF, or tracer failures remained in
  the final targeted sequence.

# Known gaps

- No runner daemon, durable spool, reconnect behavior, or network transport.
- No real harness driver or model process.
- No browser reducer or UI runtime.
- No production Paperclip adapter; control-plane persistence, authorization,
  budgets, workspaces, and finalization are intentionally absent.
- The fixture schema is Phase 0-only and is not the Phase 1 PRP schema.
