# Context

The accepted Phase 4b console proved the protocol, interaction, and visual
contract in one package-local application. Phase 5 needed to extract that
surface without changing protocol authority or turning the accepted demo into
a hidden dependency. A second consumer had to prove that the public API was
sufficient.

# Decisions

1. Package version `0.1.0` freezes four public entries: `.`, `./browser`,
   `./react`, and `./styles.css`. React and React DOM are peers. No runtime
   dependency was added.
2. The framework-free client owns HTTP/SSE transport only. Canonical events
   pass unchanged into the shared reducer; browser code does not manufacture
   identities, capabilities, request outcomes, or replay state.
3. `useRunnerConsole` exposes the accepted hook state and verbs, restores the
   session from a durable server cursor, and uses the same reducer for live and
   replay projections.
4. The component surface keeps exactly five extension points: item body,
   request detail, Composer action slots, scoped token overrides, and transport
   injection.
5. `RunnerConsoleApp` reproduces the full accepted console. The mini consumer
   is a single-column tracer bullet that imports public subpaths only and
   visibly exercises all extension points.
6. `.pcr-root` owns a light-only token sheet. One React tree is selected at
   900px; duplicate hidden mobile/desktop trees are forbidden.
7. Deterministic fake-driver tests own timing-sensitive steering, interrupt,
   request, and goal branches. The real Codex smoke owns the provider boundary,
   stable identities, redaction, safe completion, reconnect, and replay.

Full contracts are in the [SDK reference](../../docs/phase-05-sdk.md) and
[decision record](../../docs/design/phase-5-component-decisions.md).

# Failures and corrections

- The browser TypeScript configuration initially included a Node-based
  Playwright spec, which tempted the browser contract to admit Node types. The
  configuration now checks only browser application source trees and keeps its
  type environment Node-free; test and Vite configuration files use their own
  TypeScript context.
- An early hook implementation removed repeated source event IDs. That hid
  reducer input and violated parity authority. The hook now preserves the exact
  stream and lets the shared reducer classify duplicates.
- A real steering run produced an acknowledged steer and valid semantic result
  but terminalized as a provider failure. The real browser smoke now uses the
  safe completion manifest. Deterministic tests continue to prove all timing
  races without weakening terminal truth.
- The real browser server first selected the repository worktree outside its
  assigned runtime workspace. The test config now gives Codex the run-owned
  workspace directory.
- Minimal-host Chromium lacked shared libraries. The existing rootless helper
  was generalized to run a supplied package command against run-owned ARM64
  libraries.
