# Context

Phase 2 must prove one full native session without Paperclip core, a network
provider, or a real model. It extends the accepted Phase 1 validator and reducer
instead of creating a second live-state contract.

# Decisions

1. Use JSONL over stdio for mock-core-to-runner and runner-to-harness traffic.
   It is the smallest local transport and makes process ownership explicit.
2. Keep the production-direction supervisor and fake driver in Rust. Keep the
   mock core and browser client in TypeScript behind package contracts.
3. Start the fake harness in a new process group. On controller EOF, termination,
   or drop, stop the whole group with a bounded TERM-to-KILL grace period.
4. Clear inherited process environments. Restore only the executable path.
   Never forward Paperclip, model-provider, or AgentMail credentials.
5. Treat command IDs as idempotency keys and require contiguous controller
   sequence numbers before a new effect.
6. Keep log tails bounded by line and byte limits. Logs stay diagnostic and do
   not become canonical events.
7. Keep the semantic result, harness process exit, and canonical terminal event
   as three facts. Emit exactly one terminal event.
8. Use scripts for happy, request, interruption, error, duplicate-terminal, and
   cleanup scenarios. Override delay in tests to keep runs fast.
9. Validate every browser event with the Phase 1 validator and apply the Phase 1
   reducer. Replay the final event list and compare snapshots at completion.
10. Reuse the package's shadcn-style primitives and local token layer. Keep the
    live surface dense, left-flowing, and free of duplicate state labels.

# Failures and corrections

- The current run started without Cargo on `PATH`. The official stable toolchain
  was installed only under the run scratch directory.
- Chromium first failed because eight Linux libraries were absent. The system
  install path required a sudo password, so the required Ubuntu packages were
  downloaded and extracted into run scratch. Playwright then passed without a
  system change.
- The first browser attempt could not bind its loopback test port inside the
  sandbox. The same package-local test was rerun with the approved local bind.
- Review found that a TypeScript controller error killed only the runner process
  and could leave the harness group alive. The controller now closes stdin; the
  Rust runner treats EOF as cleanup, terminates the group, records exit, and
  emits one terminal event. A regression test covers this path.

# Known gaps

- No durable outbox, ACK, reconnect, or process restart recovery.
- No real harness or model session.
- No production Paperclip bridge, database, budget, approval, or status change.
- One runner owns one harness session and one scripted turn.
- The Vite middleware and in-memory live-run registry are development tools, not
  a production server.
