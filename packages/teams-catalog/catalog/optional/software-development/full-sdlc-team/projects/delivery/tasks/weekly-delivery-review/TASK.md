Review the current phase: list blockers, stalled issues and open Critical/High findings. Reassign stalled work and post a short status comment with the top three items for the week and whether the phase gate is ready.

Schedule: this routine ships without a trigger. After install, add a weekly schedule trigger with an explicit timezone, or run it on demand.
