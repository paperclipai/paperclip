# Demo Board Template — AI-Native Agency

**Target profile**: AI consulting firm or prompt engineering agency that builds AI solutions for clients. Can resell/embed Paperclip as part of their delivery stack.

## Prospect Scenario

An AI agency building custom agents and automations for enterprise clients. They need:
- A platform to deploy and manage AI agents for multiple clients
- Governance features (budgets, audit trails, review gates) to satisfy enterprise compliance
- Multi-tenant or white-label deployment options
- A faster way to build and ship agent solutions

## Demo Board Setup

### Company: [Prospect Name] AI Delivery Studio

**Agents to create:**

| Role | Title | Purpose |
|------|-------|---------|
| **Solution Architect** | Client Solutions Architect | Designs agent workflows for client needs, creates company templates |
| **Agent Builder** | Agent Configuration Specialist | Configures agents with skills, knowledge bases, and permissions |
| **QA Reviewer** | Quality Assurance Reviewer | Validates agent outputs before client delivery — approval gate |
| **Monitor Agent** | Production Monitoring Agent | Tracks agent health, budget usage, error rates across client deployments |
| **Client Success** | Client Success Coordinator | Manages client communications, feature requests, status reports |
| **Billing Agent** | Usage & Billing Tracker | Tracks per-client usage, generates invoices from metered consumption |

### Skills to enable

- **Company Templates** — Pre-built agent configurations for common use cases (support, ops, research)
- **Knowledge Management** — Client-specific knowledge bases with confidentiality boundaries
- **Plugin System** — Slack, email, API integrations for client toolchains
- **Budget & Billing** — Per-agent budget enforcement, usage metering, invoice generation
- **Plan/Review Gates** — Every agent or workflow change goes through review before deployment
- **Audit Trail** — Complete history of every action, budget decision, and approval

### Demo Flow

1. **Start**: Create a new client workspace with tailored agents for "Customer Support"
2. **Build**: Solution Architect designs workflow → Agent Builder configures 3 agents with skills
3. **Review**: QA Reviewer validates agent outputs against client requirements → approve
4. **Deploy**: Monitor Agent begins tracking production metrics
5. **Bill**: After simulated usage, Billing Agent generates an invoice
6. **Report**: Client Success sends weekly status report to client

### Value Propositions to Highlight

- **Speed to Deploy**: From client brief to working agents in days, not weeks
- **Governance**: Enterprise-ready audit trails, budgets, and review gates — no custom building
- **White-Label Potential**: Self-hosted deployment under the agency's brand
- **Scale**: Manage 50+ client deployments from a single control plane
- **Reusable Templates**: Build once, deploy for many clients with customization

### Metrics to Track

- Time from client kickoff to first agent deployment
- Number of client deployments per delivery team
- Budget accuracy (estimated vs actual agent spend)
- Client satisfaction with agent outputs
