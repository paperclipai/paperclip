# Demo Board Template — CPA / Bookkeeping Firm

**Target profile**: Solo or small CPA firm (1-5 accountants) handling bookkeeping, reconciliation, tax prep, and financial reporting for multiple clients.

## Prospect Scenario

A CPA firm managing 20-50 client books. Current pain points:
- Manual data entry from bank statements and receipts
- Time-consuming reconciliation
- Review cycles with multiple back-and-forth
- Deadline tracking across clients

## Demo Board Setup

### Company: [Prospect Name] Accounting Practice

**Agents to create:**

| Role | Title | Purpose |
|------|-------|---------|
| **Bookkeeper** | Senior Bookkeeper | Manages client books — imports transactions, categorizes, flags anomalies |
| **Recon Agent** | Reconciliation Specialist | Matches bank statements to ledger entries, flags discrepancies |
| **Reviewer** | Quality Assurance Reviewer | Reviews bookkeeper output before client delivery — approval gate |
| **Tax Prep Agent** | Tax Preparation Assistant | Organizes tax documents, calculates estimates, generates filing checklists |
| **Client Comms** | Client Communication Coordinator | Sends status updates, requests missing documents, schedules review calls |
| **Deadline Tracker** | Compliance Calendar Manager | Tracks filing deadlines, payment due dates, extension requirements |

### Skills to enable

- **Document Processing** — Receipt/bank statement parsing, categorization
- **Knowledge Base** — Tax code references, firm procedures, client preferences
- **Plan/Review Gates** — Bookkeeper output → Reviewer approval → Client delivery
- **Memory** — Client-specific preferences (charts of accounts, recurring entries)
- **Scheduling** — Deadline calendar with automated reminders

### Demo Flow

1. **Start**: Upload a month of bank statements and receipts for a sample client
2. **Watch**: Bookkeeper imports, categorizes, and reconciles transactions
3. **Review**: Reviewer checks the work, flags 2 items for correction
4. **Correct**: Bookkeeper fixes flagged items, resubmits for review
5. **Approve**: Reviewer approves → Client Comms sends summary to "client"
6. **Schedule**: Deadline Tracker shows upcoming filing dates for all clients

### Value Propositions to Highlight

- **Accuracy**: AI doesn't transpose digits or miss transactions
- **Speed**: Month-end close in hours instead of days
- **Review Confidence**: Every entry has a paper trail and reviewer sign-off
- **Capacity**: One CPA can manage 3x more clients with AI bookkeeping support
- **Compliance**: Deadline tracking + automated reminders eliminate missed filings

### Metrics to Track

- Time to close monthly books (target: <48h)
- Discrepancies caught by Review agent before client delivery
- Client capacity per CPA (before vs after)
- Compliance deadline misses (target: zero)
