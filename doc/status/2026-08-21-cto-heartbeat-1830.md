#### Technical Recommendation

**The P0 items (#1-2) must be fixed before `PAPERCLIP_BILLING_ENABLED=true` is set in production.** The fixes are:

1. **`handleCheckoutSessionCompleted`**: Replace select-then-insert with atomic upsert that handles the `company_id` unique constraint. Pre-check in `createCheckoutSession` and reject with 422 if company already has an active subscription.

2. **Both handlers**: Extract usage-row seeding into a shared function called from both `handleSubscriptionUpdated` (fallback) and `handleCheckoutSessionCompleted`, wrapped in a single transaction with the subscription upsert.

3. **Period bounds**: Align all paths to use Stripe's subscription period (`currentPeriodStart`/`currentPeriodEnd`) consistently. The query path already uses Stripe period — the seeding in `handleCheckoutSessionCompleted` and `reportUsage` must match.
