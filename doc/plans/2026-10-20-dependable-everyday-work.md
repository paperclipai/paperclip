## Qualification matrix

Six journeys, each on Codex and Claude through Slack and the board:

1. Repository task with independently verified accessible output.
2. Projectless task, repository preparation, automatic continuation, output.
3. Legacy-to-native conversion retaining configuration, followed by useful work.
4. Necessary free-text question, answer, and exactly one continuation.
5. Restart during finalization, recovery, and exactly one final delivery.
6. Active follow-up, Stop, later resumption, and retained context.

Use production instructions, recorded runtime configurations, immutable remote
images, isolated tasks, and a dedicated test channel. Negative checks cover
revocation, forged lineage, duplicate wakes, stale settings, and restricted
workspaces. Keep source, runner, model, settings, evidence, timing, cost, and
attempt identity with every result. Never infer historical qualification from
the presence of a fixture.
