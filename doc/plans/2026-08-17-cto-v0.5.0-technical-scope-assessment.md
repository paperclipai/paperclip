## Executive Summary

The v0.5.0 feature code is **substantially scaffolded but not integrated**. 
~70-80% of the feature work exists as uncommitted (untracked) files in the working tree:
services, routes, DB schema tables, migrations, shared types, and UI components
are all partially written. However, **nothing is wired in**:

- Shared package does NOT export the new notification/billing/marketplace types
- `knowledge-starter-packs.ts` source file is MISSING (only dist artifacts remain)
- `stripe` and `web-push` npm packages are NOT in any package.json
- New routes (billing, notifications, marketplace, company-templates, onboarding)
  are NOT imported in `routes/index.ts` or mounted in `app.ts`
- 3 new migrations (0137-0139) exist untracked and unapplied

**CRITICAL BLOCKER**: The server currently does NOT boot because `heartbeat.ts`
(committed, modified) unconditionally imports `notificationService` from
`notifications.ts` (untracked), which imports `DEFAULT_NOTIFICATION_PREFERENCES`
from `@paperclipai/shared` — but shared doesn't export it. This blocks ALL
v0.5.0 development.

## Current Boot Blockers

1. **`heartbeat.ts` imports `notificationService` from `notifications.ts`** (line 66)
   - notifications.ts is untracked, imports `DEFAULT_NOTIFICATION_PREFERENCES` from shared
   - shared doesn't export it → **server crashes at startup**
   - Fix: add shared exports, or gate the import behind a feature flag

2. **`company-templates.ts` imports `knowledgeStarterPackService` from `./knowledge-starter-packs.js`**
   - knowledge-starter-packs.ts source file is MISSING (only dist artifacts remain)
   - Fix: restore source file from dist, or gate import

3. **Missing npm dependencies**: `stripe`, `web-push` — not in any package.json
   - Fix: `pnpm add stripe web-push --filter @paperclipai/server`

## Risk Register

| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|------------|
| Missing source file (knowledge-starter-packs.ts) can't be recovered | Low | Medium | Rewrite from dist JS; it's a well-scoped service |
| Stripe webhook raw body parsing conflicts with Express JSON middleware | Medium | Medium | Mount webhook route before `express.json()` — verify `app.ts` ordering |
| Invite email delivery (SMTP) flaky in production | Medium | Low | Build queue with retry; separate from user-facing flow |
| Landing page scope creep ("make it beautiful") | High | Medium | Use Mintlify for V1; defer custom SSG |
| Feature flag gating — some features not ready at release | Medium | Low | Keep `authDisableSignUp` as kill switch; feature-flag Stripe behind env vars |
| Notifications hook points missed | Medium | Low | Audit domain events first; add remaining hooks in Phase 4 |
