# Paperclip v2026.1027.0

> Released: 2026-10-27

Paperclip v2026.1027.0 carries 515 commits, promoted from `2026.1023.0-beta.0`. The headline is that the Paperclip Runner is now the default for new agents: new Claude, Codex, OpenCode, and Pi agents start on the native Runner on qualified macOS and Linux hosts, existing agents get a one-click "Upgrade runner" action, and GitHub Copilot joins as a native harness. Around that: project repositories that automatically become skill sources, model-backed prompt injection prevention, agent observability to Braintrust or any OTLP endpoint, a unified Google Workspace connection, bulk edits on the Agents roster, workspaces that compact and expire themselves with encrypted restore points, and Grok Bot and Muse as experimental Runner providers. Underneath, server restarts report ready sooner, the Docker image boots from a precompiled bundle, task pages load faster, and more background services stop polling the database.

## Breaking Changes

- **The Pipelines experiment is removed.** Pipeline boards, stage settings, case automation, review queues, the `pipelines` CLI commands, the `pipelines:write` permission, the `enablePipelines` setting, and the `linkedCases` field on task detail are gone; Cases and Routines remain. Existing pipeline tables and records are preserved untouched and a stored `enablePipelines` value is ignored. ([#16834](https://github.com/paperclipai/paperclip/pull/16834))
- **Run failures no longer reach Sentry by default.** A backend DSN alone no longer reports agent run failures. Set `PAPERCLIP_SENTRY_RUN_FAILURES=unexpected` to keep the previous filtered policy or `all` to report every failed or timed-out run; the default is `off`. ([#16300](https://github.com/paperclipai/paperclip/pull/16300))
- **The run history list is bounded.** `GET /api/companies/{companyId}/heartbeat-runs` returns 200 rows by default and at most 1,000; clients that relied on an unbounded array must pass an explicit `limit`. ([#16286](https://github.com/paperclipai/paperclip/pull/16286))
- **`paperclipai agent instructions-file:delete` requires `--yes`** like the other destructive CLI commands; scripts that call it must add the flag. ([#11504](https://github.com/paperclipai/paperclip/pull/11504))

## Highlights

- **The Paperclip Runner is the default** — New Claude agents on Apple Silicon, Intel macOS, and Linux x64 ([#15993](https://github.com/paperclipai/paperclip/pull/15993), [#15997](https://github.com/paperclipai/paperclip/pull/15997)), new Codex agents on Apple Silicon, Intel macOS, Linux x64, and Linux ARM64 ([#15683](https://github.com/paperclipai/paperclip/pull/15683)), and new OpenCode and Pi agents on macOS and Linux x64 ([#17120](https://github.com/paperclipai/paperclip/pull/17120), [#17142](https://github.com/paperclipai/paperclip/pull/17142)) now start on the native Runner instead of the legacy adapter, across onboarding, the API and CLI, hires, built-ins, plugins, and imports; Linux needs GNU libc 2.39 or later, a "Legacy runner" override lives under Advanced, and existing agents keep their current runner. Existing Claude and Codex agents on qualified targets show an **Upgrade runner** action that converts them in one click, keeping model, account, and instructions and listing any settings that could not be converted ([#17122](https://github.com/paperclipai/paperclip/pull/17122)). Claude Runner agents start with their core task tools preloaded, measured about 20% faster on simple tasks ([#16885](https://github.com/paperclipai/paperclip/pull/16885)), carry the chosen effort level through resumes ([#15994](https://github.com/paperclipai/paperclip/pull/15994)), and start on Linux ARM64 ([#16372](https://github.com/paperclipai/paperclip/pull/16372)).
- **GitHub Copilot as a native harness** — Connect GitHub Copilot through Apps / AI Connections with a saved GitHub token; the agent's model list is discovered from the authenticated account, and Copilot (CLI 1.0.88) runs through the Paperclip Runner with the same instruction, permission, and completion boundaries as the other native providers, including the Linux provider manifest needed for Daytona sandboxes ([#15705](https://github.com/paperclipai/paperclip/pull/15705), [#15701](https://github.com/paperclipai/paperclip/pull/15701), [#15706](https://github.com/paperclipai/paperclip/pull/15706)).
- **Project repositories become skill sources** — GitHub repositories attached to a new project are imported as skill sources automatically: Paperclip imports their skills, re-checks the configured branch every five minutes with the setup person's GitHub connection, and installs new skills unless excluded; existing projects get an "adopt repositories" action in Skills → Sources, automatic updates can be paused, project-derived skills inherit project access, and each run pins the skill versions it started with ([#16066](https://github.com/paperclipai/paperclip/pull/16066)). Imports keep the whole repository snapshot at the scanned commit so skills that depend on shared scripts or sibling skills work after delivery, list every skill with its folder, and skip unsupported or oversized files with a warning instead of failing ([#15731](https://github.com/paperclipai/paperclip/pull/15731), [#16308](https://github.com/paperclipai/paperclip/pull/16308)). Sources gain a branch picker that loads the repository's branches, marks the default, and validates the ref before saving ([#16288](https://github.com/paperclipai/paperclip/pull/16288)); a source whose tracked branch disappeared shows a branch repair action ([#16256](https://github.com/paperclipai/paperclip/pull/16256)); each saved source is listed once with grouped refresh errors ([#16310](https://github.com/paperclipai/paperclip/pull/16310)); and disconnecting a source really removes it, with a keep-or-delete choice for the imported skills ([#16150](https://github.com/paperclipai/paperclip/pull/16150)).
- **Model-backed prompt injection prevention** — Settings → Connections lets a connection manager pick a shared OpenRouter connection and model (default `openai/gpt-oss-safeguard-20b`) to classify tool results before they reach an agent, replacing the regex verdict and allowing benign code that merely looks like an attack; costs appear in Costs, and a "Test model checks" action verifies two fixed samples. Off until configured. ([#16976](https://github.com/paperclipai/paperclip/pull/16976))
- **Agent observability to your own backend** — Company Settings → General → Agent observability sends native Codex and Claude Code logs and traces to Braintrust (US) or a custom OTLP HTTP endpoint, with credentials held in company secrets and a test action; off by default ([#16874](https://github.com/paperclipai/paperclip/pull/16874)). Braintrust also joins the Apps catalog with US and EU sign-in or API-key methods ([#17141](https://github.com/paperclipai/paperclip/pull/17141)).
- **A unified Google Workspace connection** — One Google Workspace entry replaces the separate Google service setups: pick Gmail, Drive (Docs, Sheets, Slides), and Calendar, each optionally read-only, and consent and tool access are bound to that selection; existing Google connections keep working ([#15545](https://github.com/paperclipai/paperclip/pull/15545)). Gmail gains an opt-in archive capability ([#16331](https://github.com/paperclipai/paperclip/pull/16331)).
- **Workspaces that clean up after themselves** — One hour after a task tree finishes, the terminal-workspace reaper removes regenerable directories such as `node_modules`, `dist`, and `target` that the repository's own `.gitignore` ignores, keeping the branch and all source changes; the archive cooldown drops from 7 days to 1 ([#16304](https://github.com/paperclipai/paperclip/pull/16304)). Opt-in Git cache expiration removes finished Paperclip-owned worktrees and private base clones 24 hours after the task tree is done and restores them at the exact commit when a task reopens ([#16457](https://github.com/paperclipai/paperclip/pull/16457), [#16691](https://github.com/paperclipai/paperclip/pull/16691)); with restore points on, closed worktrees that still hold unpushed commits or uncommitted files are saved to an encrypted restore point first and restored exactly when work resumes, idle open issues are parked the same way after seven days, nested multi-repository checkouts get their own restore points, and a task whose restore point has expired reopens on a fresh workspace with a note instead of failing ([#17248](https://github.com/paperclipai/paperclip/pull/17248), [#17271](https://github.com/paperclipai/paperclip/pull/17271), [#17257](https://github.com/paperclipai/paperclip/pull/17257), [#17269](https://github.com/paperclipai/paperclip/pull/17269)). Unused materialized skill versions are removed hourly and rebuilt on demand ([#16433](https://github.com/paperclipai/paperclip/pull/16433)), and host-side failover backups of remote-sandbox sessions expire a week after their issues close ([#16866](https://github.com/paperclipai/paperclip/pull/16866)).
- **Tasks with their own workspace** — A task that needs files but has no configured source now gets a stable company/task directory instead of inheriting the agent's home folder, agents can inspect, select, and request repositories for their workspace through new runner tools, and chat connections can set project and workspace defaults ([#15749](https://github.com/paperclipai/paperclip/pull/15749)); a fresh task gets its own clone when the project's default checkout contains a worktree the agent cannot read ([#16095](https://github.com/paperclipai/paperclip/pull/16095)), with a one-click Retry on a clean checkout when setup is blocked that way ([#16909](https://github.com/paperclipai/paperclip/pull/16909)).
- **Bulk edits on the Agents roster** — Select rows and filter by harness to change the AI connection, the default model, or both for many agents at once, with a preview and retry for failed updates; the roster's status selector is removed and paused agents show a badge instead of dimming ([#17215](https://github.com/paperclipai/paperclip/pull/17215)). The agent Overview shows who created an agent in companies with more than one person ([#16055](https://github.com/paperclipai/paperclip/pull/16055)).
- **Grok Bot and Muse, both experimental** — Grok Bot lets you invite an existing Grok Bot as an agent that receives assignments through a webhook routine and works through a dedicated agent-OAuth MCP connection, with guided setup, pairing codes, progress, questions, documents, and files flowing back into the task, and Stop and recovery controls; provider spending is not reported ([#16219](https://github.com/paperclipai/paperclip/pull/16219), [#16338](https://github.com/paperclipai/paperclip/pull/16338), [#16274](https://github.com/paperclipai/paperclip/pull/16274), [#16305](https://github.com/paperclipai/paperclip/pull/16305)). Muse pairs a personal Meta Muse through a wake-only receiver and Vault-backed OAuth with a ten-minute single-use ticket, with readiness, credential expiry, and disconnect controls in the invite dialog ([#16444](https://github.com/paperclipai/paperclip/pull/16444), [#16447](https://github.com/paperclipai/paperclip/pull/16447), [#16448](https://github.com/paperclipai/paperclip/pull/16448), [#16450](https://github.com/paperclipai/paperclip/pull/16450)).
- **Talk to an agent with Speko** — A Speko entry in the Apps catalog connects a Speko persona to an existing agent so you can talk to it by browser voice or phone from a task, with transcripts, call controls, inbound-line settings, phone callbacks, and call entries in Activity; shown while the **Chat connectors** experimental setting is on ([#15728](https://github.com/paperclipai/paperclip/pull/15728)).
- **Slack bots, refined** — Slack connection Settings are simplified around "Open Slack configuration" and a "Send test message" row, with "Use your own app" under Advanced ([#15679](https://github.com/paperclipai/paperclip/pull/15679)); plain direct messages always start or continue work even when **Require at-mention** is on for channel threads ([#16151](https://github.com/paperclipai/paperclip/pull/16151)); and the eyes reaction appears as soon as a mention is accepted ([#16491](https://github.com/paperclipai/paperclip/pull/16491)).
- **A sturdier GitHub review bot** — The bot keeps one main PR comment updated across pushes, ignores messages addressed to other bots, and marks stopped work accurately ([#16901](https://github.com/paperclipai/paperclip/pull/16901)); summary comments are headed with the bot's display name so several bots on one PR are distinguishable ([#16212](https://github.com/paperclipai/paperclip/pull/16212)); publication retries through GitHub 503/429 with bounded backoff and survives restarts without duplicate comments or checks ([#16284](https://github.com/paperclipai/paperclip/pull/16284), [#16883](https://github.com/paperclipai/paperclip/pull/16883)); a same-App reconnect no longer leaves a saved review showing "Working on this…" on GitHub, and an App marked as needing attention recovers on its next signed delivery ([#16259](https://github.com/paperclipai/paperclip/pull/16259), [#16263](https://github.com/paperclipai/paperclip/pull/16263)); GitHub bot tools get the gateway's 60-second maximum so `submit_review` no longer times out ([#16275](https://github.com/paperclipai/paperclip/pull/16275)); and settings show a "Reconnect GitHub" notice with reconnect-the-saved-App as the first option ([#16856](https://github.com/paperclipai/paperclip/pull/16856)).
- **More apps in the catalog** — Daytona, with personal or shared API-key credentials and 274 generated actions for sandboxes, snapshots, volumes, files, Git, and commands ([#16483](https://github.com/paperclipai/paperclip/pull/16483)); Unikraft Cloud, with actions generated from its OpenAPI specs and a per-connection default metro ([#17139](https://github.com/paperclipai/paperclip/pull/17139)); and Ditto ([#16472](https://github.com/paperclipai/paperclip/pull/16472)). A provider card with several connections collapses them behind an "N connections" row ([#16097](https://github.com/paperclipai/paperclip/pull/16097)).
- **Agent commentary in Audit** — The complaints and suggestions agents file about their tooling now have a home: Audit gains a Commentary tab with agent and type filters, text search, paging, and shareable links ([#16884](https://github.com/paperclipai/paperclip/pull/16884)), readable by every human role through a new `commentary:view` permission ([#16903](https://github.com/paperclipai/paperclip/pull/16903)).

## Improvements

## Upgrade Guide

- **Migrations `0334`–`0374`** run on upgrade. Additive schema: `0334`, `0341`, and `0342` repository skill snapshots, `project_skill_sources`, and import budgets; `0335` `chat_slack_manager_grants` and its link from Slack registrations; `0336`–`0338` execution workspace repository tables; `0339` and `0370` agent-, plugin-, and project-owned `company_secrets`; `0344` and `0346` Grok Bot tables; `0349`–`0353` Muse tables; `0357` `company_observability`; `0362` prompt injection prevention tables; `0363`–`0368` and `0371` case handoff and workflow tables; `0372`–`0374` `execution_workspace_restore_points`; `0373` interaction dismissal columns. Constraint rewrites: `0340` allows `delete` as a lifecycle-event action; `0361` allows `github` as an AI default provider. Triggers: `0347`, `0348`, and `0354`–`0356` install runtime-invalidation triggers on agents, skills, connections, grants, memberships, and secrets; `0358` bumps `issues.status_version` on assignee change; `0372` expires restore points when issues close. Row updates: `0343` backfills `agents.created_by_user_id` from the activity log; `0347` seeds one `agent_runtime` event per active agent; `0359` grants `commentary:view` to every active human membership; `0363` backfills `case_access_sources`. Indexes: `0360` adds a partial index for retained-workspace recovery; `0345` and `0369` are built `CONCURRENTLY` outside a transaction and are safe to rerun if interrupted. Expect `0343`, `0345`, and `0369` to take longer on instances with large run histories, and the check-constraint rewrites in `0339`, `0362`, and `0370` to scan `company_secrets`, `budget_reservations`, and `cost_events`.
- **New agents default to the Paperclip Runner** ([#15993](https://github.com/paperclipai/paperclip/pull/15993), [#15997](https://github.com/paperclipai/paperclip/pull/15997), [#15683](https://github.com/paperclipai/paperclip/pull/15683), [#17120](https://github.com/paperclipai/paperclip/pull/17120), [#17142](https://github.com/paperclipai/paperclip/pull/17142)): on qualified hosts (Apple Silicon, Intel macOS, Linux x64 with glibc 2.39+, and Linux ARM64 for Codex), new Claude, Codex, OpenCode, and Pi agents are created on the native Runner regardless of the `enableNativeRunner` setting. Existing agents are unchanged; choose "Legacy runner" under Advanced to opt a new agent out, or use **Upgrade runner** on an existing agent's configuration to convert it ([#17122](https://github.com/paperclipai/paperclip/pull/17122)).
- **New environment variables**, none required. Workspace cleanup: `PAPERCLIP_WORKSPACE_COMPACTION_ENABLED` (on unless exactly `false`) and `PAPERCLIP_WORKSPACE_COMPACTION_DELAY_HOURS` (default `1`) control removal of regenerable files from finished task worktrees, and `PAPERCLIP_WORKSPACE_REAPER_COOLDOWN_DAYS` now defaults to `1` instead of `7` ([#16304](https://github.com/paperclipai/paperclip/pull/16304)); `PAPERCLIP_GIT_CACHE_EXPIRATION_ENABLED` and `PAPERCLIP_GIT_BASE_EXPIRATION_ENABLED` (default `false`) with `PAPERCLIP_GIT_CACHE_EXPIRATION_DRY_RUN` (default `true`) opt into expiring finished worktrees and base clones ([#16457](https://github.com/paperclipai/paperclip/pull/16457)); `PAPERCLIP_GIT_RESTORE_POINTS_ENABLED` (default `false`) with `PAPERCLIP_GIT_RESTORE_POINT_TERMINAL_DELAY_DAYS` (default `3`), `PAPERCLIP_GIT_RESTORE_POINT_IDLE_DAYS` (default `7`, `0` disables), and `PAPERCLIP_GIT_RESTORE_POINT_RETENTION_DAYS` (default `90`) govern encrypted restore points ([#17248](https://github.com/paperclipai/paperclip/pull/17248), [#17271](https://github.com/paperclipai/paperclip/pull/17271), [#17241](https://github.com/paperclipai/paperclip/pull/17241)); `PAPERCLIP_SKILL_VERSION_RETENTION_ENABLED` (default `true`) with `_DRY_RUN` (`false`), `_KEEP` (`0`), and `_GRACE_MINUTES` (`60`) prunes unused materialized skill versions ([#16433](https://github.com/paperclipai/paperclip/pull/16433)); `PAPERCLIP_NATIVE_HARNESS_BACKUP_EXPIRATION_ENABLED` (default `true`) with `_DAYS` (`7`) and `_DRY_RUN` (`false`) expires remote-session failover backups, so reopening an issue closed longer than that window starts a fresh provider session ([#16866](https://github.com/paperclipai/paperclip/pull/16866)). Reporting: `PAPERCLIP_SENTRY_RUN_FAILURES` (`off`, `unexpected`, or `all`; default `off`) ([#16300](https://github.com/paperclipai/paperclip/pull/16300)). Claude agents also honor an existing `ANTHROPIC_BASE_URL` and `ANTHROPIC_CUSTOM_HEADERS` ([#16850](https://github.com/paperclipai/paperclip/pull/16850)).
- **New experimental settings**, all off by default: **Grok Bot** (`enableGrokBot`), which requires **Assistant connections (MCP)**, the Paperclip Runner, authenticated sign-in, and an HTTPS `PAPERCLIP_PUBLIC_URL` ([#16219](https://github.com/paperclipai/paperclip/pull/16219)); **Muse — Personal agent** (`enableMuse`), which requires the Runner and public HTTPS ([#16450](https://github.com/paperclipai/paperclip/pull/16450)); **Artifacts V1** (`enableArtifactsV1`) ([#17228](https://github.com/paperclipai/paperclip/pull/17228)). Speko voice appears under the existing **Chat connectors** setting ([#15728](https://github.com/paperclipai/paperclip/pull/15728)) and workflows under **Cases** ([#17114](https://github.com/paperclipai/paperclip/pull/17114)). `enablePipelines` is removed ([#16834](https://github.com/paperclipai/paperclip/pull/16834)). Settings → Connections is now always visible and no longer depends on **Experimental fast responses** ([#16976](https://github.com/paperclipai/paperclip/pull/16976)).
- **`commentary:view` for every human role** ([#16903](https://github.com/paperclipai/paperclip/pull/16903)): migration `0359` and startup seeding grant the new permission to every active human membership, including viewers, so anyone in the company can open Audit → Commentary. Deleting that grant from a member is temporary: startup seeding re-adds every role-default grant for each active human member on the next server start, and this release has no durable way to withhold it. Source-task privacy still filters what each person sees in commentary.
- **Sentry operators** ([#16300](https://github.com/paperclipai/paperclip/pull/16300)): set `PAPERCLIP_SENTRY_RUN_FAILURES=unexpected` to keep receiving run-failure events; they are off by default even with `SENTRY_DSN_BACKEND` configured.
- **API clients**: the run history list is capped at 1,000 rows (default 200) ([#16286](https://github.com/paperclipai/paperclip/pull/16286)); the `linkedCases` field and all Pipeline routes are gone ([#16834](https://github.com/paperclipai/paperclip/pull/16834)); a PATCH that replaces `executionPolicy` and sets `done` during a live review cycle returns `422 unexecuted_review_stage` ([#13178](https://github.com/paperclipai/paperclip/pull/13178)); and anything parsing GitHub review summary headings must accept bot names ([#16212](https://github.com/paperclipai/paperclip/pull/16212)).
- **Custom Docker images** ([#16672](https://github.com/paperclipai/paperclip/pull/16672)): the shipped image now starts with `node server/dist-runtime/index.mjs`; images that invoked `server/dist/index.js` through tsx should switch to the runtime bundle.
- **Default views change**: agent- and system-created tasks are hidden from task lists until you enable "show agent-created tasks" ([#16157](https://github.com/paperclipai/paperclip/pull/16157)), and Inbox "Mine" no longer includes automation you did not take part in ([#16356](https://github.com/paperclipai/paperclip/pull/16356)).
- **Google Workspace** ([#15545](https://github.com/paperclipai/paperclip/pull/15545)): new Google Workspace requests depend on the Paperclip-hosted OAuth broker update, and older brokers reject them; existing per-service Google connections keep working.
- **Harness pins** are unchanged from v2026.1023.0: Codex 0.160.0, Claude Agent SDK 0.3.286 (Claude Code 2.1.286), and OpenCode 1.18.34. GitHub Copilot ships at CLI 1.0.88 ([#15701](https://github.com/paperclipai/paperclip/pull/15701)).
