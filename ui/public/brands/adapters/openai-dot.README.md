# Dot mark

`openai-dot.svg` is the unmodified Dot ring mark linked by OpenAI's public [Introducing dots](https://openai.com/index/introducing-dots/) announcement.

Source: https://images.ctfassets.net/kftzwdyauwt9/KKSjto3MtJguvsLQsM1Bp/1704a6937d22b1bb3cac38dc5f43f9df/dots-o.svg

Retrieved 2026-10-08. Used to identify the Dot provider in Paperclip setup UI. Hermes uses the existing `hermesagent.svg` and `hermesagent-dark.svg` assets.
