## 五、审计结论

**final_status = PARTIAL**

依据:
1. **工程链路四项全 PASS**:typecheck exit 0;build exit 0(21.57s);40 locale × 7857 keys 与基准完全一致;zh-CN 无空值。i18n 框架接入本身是健康的,无结构风险。
2. **但「完成汉化」未达成**:界面仍残留约 250 处真实英文文案(重灾区:IssueThreadInteractionCard 操作按钮态、InstanceExperimentalSettings 整页 aria-label、CompanySkills/Dashboard/CommandPalette 操作入口);zh-CN 存在约 460 条质量缺陷,其中 172 条「去空格英文」是肉眼可辨的坏翻译,任何用户翻到技能库/详情页都会看到。
3. 新增 key 抽查 85% 合格,说明主体翻译质量尚可,缺陷集中在特定批次/特定形态(多行文本节点、非标 Label 属性、去空格管道),可定向收敛。

对照验收口径:若验收线为「typecheck/build/locale 结构正确」则 PASS;若验收线为「核心界面默认语言全中文 + 翻译可读」(即「完全汉化」的产品含义)则为 PARTIAL——本报告按后者从严判定。

## 六、修复建议(只读建议,本审计未改动文件)

按投入产出排序:

1. **P0 · 修 172 条去空格英文(locale-only,零组件风险)**
   清单:/private/tmp/zh_quality_v2.json → `despaced` 字段(key + en 原文齐全)。用 en 原文重新翻译覆盖 zh-CN 对应 key 即可,如 `index.tryAgain: "Tryagain." → "请重试。"`,`companySkills.includesAssets → "包含 assets"`。纯 JSON 改动,typecheck/build 不受影响。

2. **P0 · 修 2 条抽查硬伤**
   - `app.policiesTab.noRulesYet`:`"无规则尚未"` → `"暂无规则"`
   - `app.projectDetail.managedBy`:`"受管由"` → `"管理方:"`(注意 en 尾随空格的插值拼接方式)

3. **P1 · IssueThreadInteractionCard.tsx 按钮态(约 15 处,单文件收口)**
   该文件已有成熟 t() 用法与前缀,直接补 key:
   `:1896 Approving…` → `{t("app.issueThread.approving", { defaultValue: "Approving…" })}`(同模块现有前缀为准,先 grep 该文件 `t\("` 取众数前缀);
   `:2620 Attach screenshots`、`:1705 View result`、`:1128 Ask user questions` 同法。key 写入 en+zh 并同步其余 39 个 locale(en fallback)。

4. **P1 · InstanceExperimentalSettings.tsx aria-label(21 处)**
   `ariaLabel="Toggle apps experimental setting"` → `ariaLabel={t("app.instanceExperimental.toggleApps", { defaultValue: "Toggle apps experimental setting" })}`。aria-label 不影响布局,风险最低。

5. **P2 · 其余 ns_prop/emptyMessage 长尾(约 200 处,~90 文件)**
   按 skill「同一英文词多形态一次清完」规则:对 `noneLabel/copiedLabel/allLabel/emptyMessage` 逐形态替换;跨行文本节点(102 处)须按「换行+缩进」精确匹配,`>text<` 正则抓不到。建议分 2–3 个并行批次 fan-out,每批只改自己的文件、locale 映射统一交主 agent 合并(skill 有完整流程)。

6. **P3 · 混杂 242 条逐条过一遍**
   ACP/Acme/Board/Hermes 等专名可保留;机翻拼接句(如 cheap 配置文件两条)重译。清单:/private/tmp/zh_quality_v2.json → `true_mixed`。

修复后复跑本审计三件套(typecheck + build + 本报告 §二/§三 脚本)即可闭环验证;预期 P0–P1 完成后残留可降至 <80 处、zh 缺陷降至 <150 条。
